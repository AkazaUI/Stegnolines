Zero-Key Hidden Message Extraction Guide

The Stegoanalysis tool (steganalysis.html) allows you to analyze text for hidden Unicode characters, classify techniques, and extract secret messages without requiring pre-shared keys.

Step-by-Step Workflow

  1. Analyze Text: Paste any suspicious message into the input text area and click Analyze Text.
  2. Detection & Classification: Review the live metric cards, visual diff map, and carrier table.
  3. Extract Hidden Message: Click «استخراج الرسالة المخفية» / "Extract Hidden Message" to trigger the zero-key extraction engine.
  4. Inspect Extraction Tabs:
    • Verdict: Confirmed scheme and confidence level.
    • Decoded Message: Extracted payload rendered safely with security warnings.
    • Encoding Details: Breakdown of carrier mapping and decapsulation steps.
    • Carrier Inventory: Table of all code points with legitimacy classifications.
    • Alternative Candidates: Other hypotheses evaluated by the engine.
    • Sanitized Output: Clean text stripped of suspect steganographic characters.
  5. Export Report: Export forensic reports in JSON or Markdown formats for audit trails.
