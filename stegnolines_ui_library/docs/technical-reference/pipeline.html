Steganography pipeline

The pipeline is implemented in staged modules under js/stage3_hide/.

Stages

  2. PRNG / key derivation (step2_prng.js)
  3. XOR layer (step3_xor.js)
  4. Variable-width codec (step4_vs_codec.js)
