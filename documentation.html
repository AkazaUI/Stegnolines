What is StegoLines (Stegnolines)?

StegoLines is an open-source, client-side cryptographic steganography platform that conceals encrypted messages and miniature images within ordinary text using zero-width Unicode characters.

How does text-based steganography achieve zero visual distortion?

The system encrypts payloads using PBKDF2-derived AES-256-CTR and maps ciphertext bits into invisible Unicode codepoints (Zero-Width Non-Joiner, Zero-Width Space, and Variation Selectors) without altering visible typography or character spacing.

Can hidden messages survive transmission through WhatsApp, Telegram, or Messenger?

Yes. StegoLines integrates a Social Platform Guard that applies adaptive Unicode formatting and anti-sanitization encoding, achieving a verified 100% extraction survival rate across 9 major communication channels.

Is any user data or secret key sent to remote servers?

No. StegoLines executes 100% client-side in the user's browser using the native Web Crypto API. No plaintext, ciphertext, secret keys, or cover texts are ever transmitted over the network.

How can I detect and analyze hidden text steganography?

You can use the built-in Text Steganalysis and Forensic Engine at /steganalysis to inspect Unicode codepoints, detect zero-width characters and homoglyph anomalies, and analyze character entropy.
