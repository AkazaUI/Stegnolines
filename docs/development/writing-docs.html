Scientific Documentation Guidelines

The STEGNOLINES documentation system is organized into modular HTML articles rendered with dynamic bilingual navigation, automatic table-of-contents generation, and instant search indexing.

1. Adding or Updating Documentation Articles

  1. Register Navigation Item: Add the new article definition inside js/docs/nav-data.js under the corresponding section array.
  2. Update Multilingual Dictionaries: Add translation keys for the title, breadcrumbs, and descriptions in js/i18n/docs.js for both English and Arabic.
  3. Create Article HTML File: Place the static HTML file in the appropriate docs/ subdirectory (e.g. docs/getting-started/, docs/user-guide/, or docs/technical-reference/).
  4. Include Standard Head & Footers: Ensure the article references design tokens (tokens.css / main.css / docs.css) and dynamic placeholders (#navbar-placeholder and #footer-placeholder).

2. Typography & Code Standards

  • Heading Hierarchy: Use a single <h1> tag per article, followed by <h2> and <h3> sub-sections. The TOC engine will automatically generate anchor links.
  • Math Formulations: Wrap mathematical definitions inside <div class="math-box"> blocks for high-contrast, LTR-aligned display across all language modes.
  • Callout Boxes: Use <div class="docs-note">, <div class="docs-alert-info">, or <div class="docs-alert-warning"> to emphasize critical architectural requirements.
  • Tables: Enclose comparative or empirical data tables in <div class="docs-table-wrapper"> to ensure responsive horizontal scrolling on mobile viewports.
