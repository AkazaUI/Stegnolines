Chat Platform Integration & Scanner Engine

When users copy chat threads containing multiple messages from social media applications, metadata (such as timestamps, sender names, and line breaks) is included in the clipboard. The Scanner Engine automates message isolation, candidate identification, and zero-effort decryption.

1. Supported Social Platforms

The scanner features format signatures optimized for major instant messaging and social platforms:

  • WhatsApp: [DD/MM/YYYY, HH:MM:SS] Sender: Message and Android/iOS copy variations.
  • Telegram: Sender, [DD.MM.YY HH:MM] Message.
  • Instagram Direct: Direct chat bubbles and multi-line message exports.
  • X (Twitter), Facebook Messenger, TikTok & YouTube: Handles unstructured pasted text and comments.

2. Scanner Extraction Pipeline (4 Phases)

Scanner Pipeline Execution

1. Phase 1 — Ingestion: The receiver selects the target platform (or generic mode), enters the Stego-Key, and pastes the entire chat transcript.

2. Phase 2 — Segmentation & Filtering: The scanner splits the transcript into individual message blocks and tests each block for the presence of Unicode Variation Selectors.

3. Phase 3 — Candidate Extraction: The message containing the hidden payload is isolated, its VS bytes are extracted, and reverse XOR mapping retrieves the encrypted bytes.

4. Phase 4 — Decryption & Decompression: AES-256-CTR decrypts the payload, Brotli decompresses the byte array, and the revealed secret is presented.

3. Fallback Carrier Matching

If multi-line forwarding separates the carrier text from surrounding chat headers, the scanner uses a candidate loop: it tests each clean text line against the extracted Variation Selectors until cryptographic integrity assertions pass, ensuring zero extraction failures.
