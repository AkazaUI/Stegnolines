Capacity & hints

Understanding Shannon capacity constraints and zero-overhead hint mechanisms is crucial for utilizing steganographic systems effectively.

Shannon Capacity & Text Carrier Metrics

Each character in the cover text provides a finite number of bits. In JavaScript, strings are UTF-16 encoded, yielding 16 bits per character. The maximum Shannon capacity $C_{max}$ in bits is determined by: $$C_{max} = 16 imes N_{char}$$ Where $N_{char}$ is the number of characters in the cover text. The payload bit length $K$ must satisfy $K le C_{max}$. The capacity indicator in the UI alerts you through green (safe), yellow (warning), and red (critical) states.

Zero-Overhead Hint Ingress

STEGNOLINES packages the secret message and hint into a unified byte stream. When a hint is present, a separator byte is injected between them: $$ ext{Payload} = [ ext{Message Bytes}] + [0 ext{xFF}] + [ ext{Hint Bytes}]$$ The byte $0 ext{xFF}$ is an illegal byte in the UTF-8 specification, which means it can NEVER appear in valid UTF-8 text. Therefore, $0 ext{xFF}$ serves as an absolute, zero-overhead boundary marker that can be recognized instantly during extraction without adding any padding or sizing metadata!
