Zero-Key Stegoanalysis Extraction Guide

The Stegoanalysis forensics interface (steganalysis.html) enables forensic analysts and investigators to inspect suspicious digital messages, detect invisible Unicode characters, classify concealment schemes, and extract payloads without requiring pre-shared encryption keys.

1. Forensic Analysis Workflow

  1. Ingest Suspicious Message: Paste any message into the inspection textarea and click Analyze Text.
  2. Detection & Metric Classification: Review the live statistics cards (Hidden character count, entropy anomaly index, suspected scheme classification).
  3. Visual Diff Map & Carrier Table: Inspect the high-contrast carrier inventory table detailing code points, Unicode planes (BMP vs SSP), and glyph legitimacy.
  4. Trigger Zero-Key Extraction Engine: Click «استخراج الرسالة المخفية» / "Extract Hidden Message" to initiate the heuristic decapsulation pipeline.

2. Forensic Diagnostic Report Tabs

  • Verdict & Confidence: Summary of identified steganography algorithm and forensic confidence score.
  • Decoded Payload: Extracted payload rendered safely with active sanitization against DOM-based XSS attacks.
  • Encoding Breakdown: Step-by-step trace of carrier separation, byte realignment, and decapsulation operations.
  • Sanitized Clean Output: Copyable version of the cover text with all steganographic bytes stripped.
  • Audit Report Export: Export standardized forensic audit trails in JSON or Markdown formats for forensic reporting.
