Experimental Results & Empirical Benchmarks

This chapter presents the empirical findings obtained during formal laboratory testing across four baseline cases, measuring capacity, compression efficiency, stego-text expansion, security brute-force resilience, and social media survival.

1. Reference Baseline Test Cases

  • Case 1 (Small Arabic Cover + Secret URL): Cover: 48 chars (88 bytes Arabic). Secret: 53 chars URL (53 bytes).
  • Case 2 (Large English Cover + Long Secret Paragraph): Cover: 803 chars (803 bytes English). Secret: 707 chars paragraph (707 bytes).
  • Case 3 (1:1 Equal Size English Cover + Arabic Secret): Cover: 57 chars (57 bytes English). Secret: 31 chars Arabic (57 bytes).
  • Case 4 (Capacity Limit Violation): Cover: 20 chars (20 bytes English). Secret: 141 chars message (141 bytes) → Graceful failure assertion.
