Configuration & Runtime Parameters

This technical guide details the configurable operational parameters, cryptographic constants, and buffer allocations governing the STEGNOLINES client-side engine.

1. Core Pipeline Runtime Parameters

Parameter Name Default Value Permitted Range / Type Architectural Function
PBKDF2_ITERATIONS 100,000 Integer (≥ 100k) Key stretching rounds to prevent GPU-accelerated brute-force attacks.
BROTLI_QUALITY 11 0 to 11 Maximum Brotli compression ratio for natural text payload reduction.
BROTLI_CHUNK_SIZE 4096 bytes 1024 to 65536 Internal streaming buffer size for WebAssembly memory allocation.
COMPRESSION_FLAG 0xFE Byte (Hex) Unique protocol prefix indicating that Brotli stream decompression is required.
MAX_HINT_LENGTH 60 chars 0 to 60 Prevents UI bloating and memory exhaustion attacks in the recovery log.
MAX_JSON_UPLOAD 50 KB ≤ 50 KB Limits hints JSON import size to guard against client-side tab freezes.

2. Steganography Fallback Logic

  • Key-Base Auto-Binding: If the user leaves the AES Key-Base password field blank, the engine deterministically assigns the value of the Stego-Key as the password.
  • Auto-Generated Stego-Key: If the Stego-Key is omitted, the system generates a deterministic seed by taking the SHA-256 hash of the plain cover text.
  • Compression Bypass Mode: If Brotli compression does not reduce payload size (e.g. for short random strings), the system automatically transmits raw UTF-8 bytes to save capacity.
