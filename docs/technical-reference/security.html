Cryptographic & Security Model

STEGNOLINES establishes a multilayered defense-in-depth model that combines NIST-compliant symmetric encryption, heavy PBKDF2 key stretching, dynamic cover hashing, and pseudorandom spatial diffusion.

1. Tri-Layer Defense in Depth

Tri-Security Layer Architecture

1. Cryptographic Layer (Confidentiality): AES-256-CTR stream cipher transforms the message into high-entropy ciphertext with 0 bytes padding overhead.

2. Key Diversification Layer (Brute-Force Resistance): PBKDF2-HMAC-SHA256 with 100,000 iterations and a 16-byte salt extracted dynamically from the SHA-256 hash of the cover text.

3. Steganographic Spatial Layer (Unobservability): AES-256-CTR CSPRNG with Unbiased Rejection Sampling and PBKDF2-HMAC-SHA256 (100,000 rounds) key derivation scatters message bits across pseudorandom cover indices, eliminating modulo bias and masking the payload inside innocent text.

3. Steganalysis Resistance & Forensic Visualizers

The application includes an advanced Forensics Diagnostics Dashboard that gives security auditors full transparency into the spatial encoding:

  • Steganography Hex Stream: Live view of injected Variation Selector code points (U+FE00–U+FE0F and U+E0100–U+E01EF).
  • PRNG Random Base Positions: Visual table of the deterministic character indices chosen by the CSPRNG generator.
  • Binary XOR Key Difference Mask: Interactive visual matrix displaying active bit flips versus matched carrier bits with real-time entropy calculation.
