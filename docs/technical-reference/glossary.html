Terms, Acronyms & Scientific References

This reference contains the formal glossary of cybersecurity and steganographic acronyms along with the complete bibliography of peer-reviewed scientific citations from the project research.

1. Master Terms & Acronyms Table (Table 10.1)

Acronym Full Term & Technical Definition
AESAdvanced Encryption Standard — FIPS 197 symmetric block cipher standard.
AES-CTRAdvanced Encryption Standard in Counter Mode — Stream cipher mode with 0-byte overhead.
ASCIIAmerican Standard Code for Information Interchange — 7-bit character encoding.
CIAConfidentiality, Integrity, Availability — Foundational cybersecurity triad.
CTCover Text — The innocent carrier medium used to conceal secret messages.
CVECommon Vulnerabilities and Exposures — Standardized cybersecurity flaw identifiers.
DOMDocument Object Model — In-memory programmable node tree of HTML documents.
FPEFormat-Preserving Encryption — Encrypts data while maintaining exact character format.
HMACHash-Based Message Authentication Code — Keyed cryptographic authentication function.
IVInitialization Vector — Initial state block used to seed stream cipher counters.
LZWLempel–Ziv–Welch — Dictionary-based lossless data compression algorithm.
NISTNational Institute of Standards and Technology — United States standards authority.
PBKDF2Password-Based Key Derivation Function 2 — High-entropy cryptographic key stretching standard.
CSPRNG / PRNGCryptographically Secure Pseudo-Random Number Generator — Deterministic cryptographic random sequence generator (AES-256-CTR CSPRNG with Dual-Engine Fallback to Mulberry32).
SHA-256Secure Hash Algorithm 256-bit — Cryptographic one-way 32-byte digest (FIPS PUB 180-4).
STSecret Text — The confidential payload message concealed inside the carrier.
UTF-8Unicode Transformation Format 8-bit — Variable-width character encoding standard.
VSVariation Selectors — Invisible Unicode combining characters (U+FE00–U+FE0F & U+E0100–U+E01EF).
WASMWebAssembly — W3C high-performance binary bytecode execution target for browsers.
XORExclusive OR — Fundamental bitwise logic gate utilized for spatial mapping ($K = C \oplus M$).
XSSCross-Site Scripting — Code injection attack targeting client DOM contexts.
ZWCZero Width Characters — Non-printing Unicode control symbols (e.g. ZWNJ, ZWJ).
